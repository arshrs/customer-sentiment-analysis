# Customer Sentiment Analysis

A full-stack AI-powered sentiment analysis application that classifies customer reviews as positive or negative using Natural Language Processing (NLP) and Machine Learning.

The application features a React frontend, an Express.js backend, and a Python-based machine learning model trained using TF-IDF vectorization and Logistic Regression. Users can enter review text and receive real-time sentiment predictions through an interactive web interface.

## Features

* Real-time sentiment prediction
* Modern React user interface
* Express.js API backend
* Python ML inference engine
* TF-IDF text vectorization
* Logistic Regression classification
* Dynamic sentiment visualization

## Tech Stack

* React.js
* Node.js
* Express.js
* Python
* Scikit-learn
* Pandas
* TF-IDF Vectorizer
* Logistic Regression

## Machine Learning Pipeline

1. Text preprocessing
2. TF-IDF feature extraction
3. Logistic Regression model training
4. Real-time inference
5. Sentiment classification output
